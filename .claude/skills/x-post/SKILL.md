# X 告知文の作成

沖縄Ruby会議03 のお知らせを X で告知するための文言を作る。

## 1. 元記事を読む

- URL `https://ruby.okinawa/okrk03/news/<slug>/` は `_posts/YYYY-MM-DD-<slug>.md` に対応する(`_config.yml` の `permalink: /news/:title/`)。
- ローカルの作業ブランチに記事がまだないことがあるので、まず `git fetch` してから `origin/gh-pages` を読む。
  ```sh
  git fetch -q
  git ls-tree -r --name-only origin/gh-pages | grep <slug>
  git show origin/gh-pages:_posts/YYYY-MM-DD-<slug>.md
  ```
- 記事が別のページへのリンクで中身が少ないとき(例: `area/index.html`)は、リンク先のページも読んで具体的な情報を拾う。
- 書いてあることだけを使う。記事にない日付・数字・おすすめなどは作らない。

## 2. 文言のルール(必須)

- ハッシュタグ `#okrk03` を必ず入れ、いちばん最後の行に置く。
- 絵文字は次の3つを優先して使う。最初に出す絵文字ほど優先度が高いので、🌺 を見出しや冒頭に、🐍 を締めのほうに置く。
  1. 🌺
  2. 🏝️
  3. 🐍
- 内容に合う絵文字(宿泊なら 🏨、日付なら 📅 など)を足してもよい。ただし上の3つより目立たせない。
- URL は本文とハッシュタグの間に、独立した行で置く。
- 重み付きの文字数で 280 以内に収める(全角文字・絵文字は 2、URL は長さに関係なく 23)。

## 3. 構成

採用された文言の見本:

```
🌺 会場・宿泊エリア案内を公開しました 🌺

沖縄Ruby会議03の会場「桜坂劇場」周辺の宿泊エリアについて、6エリアの特徴と会場までの徒歩の目安をまとめています 🏝️
牧志・国際通り/平和通り/松尾/美栄橋/安里・栄町/松山・久茂地

宿を探すときの参考にどうぞ 🐍

https://ruby.okinawa/okrk03/news/area-guide/

#okrk03
```

- 1行目: 🌺 で挟んだ見出し(何を公開・開始したか)
- 本文: 記事の要点を1〜2文。具体的な名前や数字があれば入れる
- 締め: 読んだ人にしてほしいことを一言
- URL
- `#okrk03`

## 4. 出力

1. 切り口を変えた案を 3 つ作る(例: 標準 / 短め / 特定の読者向け)。
2. 各案の文字数を数え、280 を超えた案は削ってから出す。
   ```sh
   ruby .claude/skills/x-post/count.rb <<'EOF'
   (文言)
   EOF
   ```
3. 各案をコードブロックで示し、案ごとに文字数(`NNN / 280`)を添える。
4. 推測で決めたこと(切り口、読者の想定など)があれば、最後に短く書く。
